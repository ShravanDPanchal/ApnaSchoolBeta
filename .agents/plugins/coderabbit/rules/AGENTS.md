# CodeRabbit Code Review Rules

- **Signal Over Noise**: Focus on actionable bugs, security holes, and architectural flaws rather than purely cosmetic formatting if a linter/formatter handles it.
- **Provide Actionable Fixes**: When pointing out an issue or suboptimal pattern, always provide a concrete code snippet demonstrating the recommended fix.
- **Check Edge Cases**: Always verify nullability, array bounds, async exception handling, and database transaction rollbacks.
