# GSD (Get Shit Done) Operational Rules

- **Default to Autonomous Execution**: Take initiative on implementation details following industry best practices.
- **Milestone Validation**: Never consider a task complete without running and passing verification tests or builds.
- **Error Persistence**: When encountering compiler, linter, or test failures, diagnose and fix them autonomously up to standard limits before asking the user.
- **Maintain Code Quality**: Do not use placeholders (e.g. `// TODO: implement later`) in final deliverables.
